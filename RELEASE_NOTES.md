## TV Cleaner — БЕТА

Чистка Android TV по сети: с телефона или с компьютера Windows. Без root, ничего не ставится на сам ТВ.

**Это бета-версия.** Проверена не на всех ТВ. Список «мусора» составлен по общим знаниям и может быть неточным для твоей модели.

### Что скачать
- `TVCleaner-Android.apk` — для телефона на Android
- `TVCleaner-Setup.exe` — установщик для Windows
- `TVCleaner-Portable.zip` — Windows без установки: распакуй и запусти `TVCleaner.exe`

### Что умеет
- Находит ТВ в сети и подключается
- Скан: «Мусор» (безопасно) и «Можно отключить» (с пояснением, что пропадёт)
- Очистка кэша, освобождение памяти, меньше анимаций
- Бэкап перед каждой чисткой и откат в один тап
- Смена лаунчера на лёгкий

### Установка
1. На ТВ: Настройки → О приложении → 7 раз «Сборка» → Для разработчиков → «Отладка по сети».
2. Телефон или компьютер должны быть в той же сети, что и ТВ.
3. Установи приложение. Телефон и Windows могут показать предупреждение (приложение без платной подписи): нажми «Всё равно установить» или «Подробнее → Выполнить в любом случае».
4. Вкладка «ТВ» → «Найти ТВ в сети» → «Подключиться», на ТВ разреши запрос.

### Перед использованием
- Начни с «Мусора», потом перезагрузи ТВ и проверь, что всё работает.
- Если что-то пропало, открой вкладку «Бэкапы» → «Восстановить».
- Ты делаешь это на свой риск. Авторы ответственности не несут.
